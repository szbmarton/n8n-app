Privacy Policy

Last updated: November 5, 2026

1. About this application

Personal Email Calendar Assistant is a private application operated and used exclusively by its owner. It is not offered to the public or made available to other users.

The application connects to the owner's Gmail and Google Calendar accounts to identify events in emails and create corresponding calendar entries.

2. Data access and usage

With the owner's authorization, the application accesses Gmail messages and uses their content to identify relevant event information, such as titles, dates, times, locations, and descriptions.

This information is used exclusively to create events in the owner's Google Calendar.

3. Data storage

All application data is stored locally on the owner's private home server, including:

  • Processed email content and extracted event information.
  • Google OAuth refresh tokens.

The application does not use third-party cloud storage for this data.

Email content is not stored in application logs. Logs contain only technical and operational information.

4. Data sharing

The application does not sell, rent, or share personal data with third parties.

Google data is used exclusively for the application's email-to-calendar functionality. Communication with Google servers is necessary to access Gmail and create Calendar events.

5. Security and access

The application runs on the owner's private home network and is intended for the owner's exclusive use.

Reasonable measures are taken to protect locally stored data and Google authorization credentials against unauthorized access.

6. Revoking access and deleting data

The owner can revoke the application's Google account permissions at any time:

Google Account Permissions

Locally stored application data and authorization credentials can be deleted directly from the home server.

7. Google API compliance

The application's use of Google user data adheres to the Google API Services User Data Policy , including its Limited Use requirements.
